# بورتفوليو نور أحمد

موقع شخصي عربي متجاوب مبني بـ HTML وCSS وJavaScript فقط. لا يحتاج إلى تثبيت حزم أو إعداد خادم.

## التشغيل

افتحي `index.html` في المتصفح. الصور والخطوط تستخدم روابط خارجية، لذلك يلزم اتصال بالإنترنت لعرضها.

## التخصيص

- غيّري الاسم والعنوان والنبذة والموقع في `index.html`.
- استبدلي `hello@example.com` ببريدك الإلكتروني، وحدّثي روابط LinkedIn وGitHub.
- استبدلي روابط الصور وعناوين المشاريع وصورها في قسم المشاريع.
- حدّثي قائمة المهارات والتقنيات بما تستخدمينه فعلًا.
- عدّلي الألوان الأساسية من متغيرات `:root` في `styles.css`.

## الملفات

- `index.html`: المحتوى العربي والأقسام وروابط التواصل.
- `styles.css`: الهوية البصرية وتنسيق الشاشات المختلفة.
- `script.js`: قائمة الهاتف، تصفية المشاريع، السنة الحالية، وتأثير ظهور العناصر.

التفاعلات الأساسية تعمل محليًا دون إعداد. الصور والخطوط الحالية أمثلة خارجية قابلة للاستبدال بملفاتك.
